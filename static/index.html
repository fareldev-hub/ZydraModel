    Endpoints

    Contoh penggunaan API

    Semua route yang berinteraksi dengan model atau mengelola API key membutuhkan credential. Status layanan dapat diakses tanpa key. Gunakan API key pada header agar tidak bocor ke access log URL.

    Node.js backend (Express)

    Simpan key di environment server, jangan kirim master/key dari frontend publik.

    import express from "express";

const app = express();
app.use(express.json());

app.post("/ask", async (req, res) => {
  const response = await fetch("http://localhost:8000/v1/chat/completions", {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      "X-API-Key": process.env.ZYDRA_API_KEY
    },
    body: JSON.stringify({
      model: "zydra-lora",
      messages: [{ role: "user", content: req.body.prompt }]
    })
  });
  res.status(response.status).json(await response.json());
});

app.listen(3000);

    Python backend

    import os
import requests

response = requests.post(
    "http://localhost:8000/v1/chat/completions",
    headers={"X-API-Key": os.environ["ZYDRA_API_KEY"]},
    json={
        "model": "zydra-lora",
        "messages": [{"role": "user", "content": "Jelaskan fotosintesis secara singkat."}],
    },
    timeout=120,
)
response.raise_for_status()
print(response.json()["choices"][0]["message"]["content"])
