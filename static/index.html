Pilih endpoint, tekan Try it out, isi parameter bila diperlukan, lalu jalankan request dan lihat response JSON.

Endpoints

Contoh penggunaan API

Semua route yang berinteraksi dengan model atau mengelola API key membutuhkan credential. Status layanan dapat diakses tanpa key. Gunakan API key pada header agar tidak bocor ke access log URL.

Node.js backend (Express)

Simpan key di environment server, jangan kirim master/key dari frontend publik.

import express from "express";

const app = express();
app.use(express.json());

app.post("/ask", async (req, res) => {
  const response = await fetch("http://localhost:8000/v1/prompt", {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      "X-API-Key": process.env.ZYDRA_API_KEY
    },
    body: JSON.stringify({ prompt: req.body.prompt })
  });
  res.status(response.status).json(await response.json());
});

app.listen(3000);

JavaScript fetch

Gunakan API key yang dibuat dari UI. Untuk aplikasi browser publik, panggil backend milikmu agar key tidak terekspos.

const response = await fetch("http://localhost:8000/v1/prompt", {
  method: "POST",

    "Content-Type": "application/json",

Python backend

import os
import requests

response = requests.post(
    "http://localhost:8000/v1/prompt",
    headers={"X-API-Key": os.environ["ZYDRA_API_KEY"]},
    json={"prompt": "Jelaskan fotosintesis secara singkat."},
    timeout=120,
)
response.raise_for_status()
print(response.json()["response"])
